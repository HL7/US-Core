The files contain Value Set Packages that contain all the expanded value sets required for an implementation guide. US Core publishes annual value set packages that contain value sets expanded with updated code system versions for each release year. These packages are available for several US Core Versions to help implementers as JSON, XML, or CSV and a corresponding zip file containing the selected Value Set Package.  See https://confluence.hl7.org/spaces/CGP/pages/453907194/Value+Set+Packages for more information.
